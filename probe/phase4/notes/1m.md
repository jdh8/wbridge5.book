## Not probeable with this harness

- Opener-side maximal double where the auction needs South to make two own
  calls between scripted ones in a way it may not choose; only responder side
  is probed.
- Doc 610 "(其它) treat as 1♥": many RHO calls; only the pass branch probed.
- 1m (1♠) 2m (2♦) INV 3♥ (rare RHO call); 3-level support doubles (3♦/3♠).
- Vulnerability effects; all lines are none vul.
